# Anduril 2 Controls

An interactive, mobile-friendly reference for the **Anduril 2** flashlight UI.
Pick a state (Off, On, Lockout, Strobes, Battery check, …) and drill through
every click and config menu, with a breadcrumb back-path. Switch between the
Simple and Advanced interfaces right on the map.

**Live:** https://diRk262.github.io/anduril2/

## Features

- Interactive state map — tap a state to see every click it offers
- Drill-down into modes and config menus (e.g. `3C → 2C → 7H`) with breadcrumbs
- Toggle Simple ⇄ Advanced UI, switchable from the map itself
- Works on desktop (node graph) and phones (vertical tree) — no horizontal scrolling
- Light & dark theme, single self-contained HTML file
- Content checked against the official Anduril 2 manual
